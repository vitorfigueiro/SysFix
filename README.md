# Controle de Equipamentos (Web Version)

Aplicação Web desenvolvida em Python para controle e gerenciamento de fila de chamados, técnicos e equipamentos.

## 🚀 Tecnologias Utilizadas
- **Backend:** Python, FastAPI, Uvicorn
- **Frontend:** HTML5, Tailwind CSS, Jinja2
- **Banco de Dados:** PostgreSQL (`psycopg2-binary`)
- **Relatórios:** ReportLab (Geração de PDFs)
